# SURVEY-FORM

Professional, shareable Transport Department satisfaction survey form for **RT Knits**.

## How to use

1. Open `/home/runner/work/SURVEY-FORM/SURVEY-FORM/index.html` in any modern browser.
2. Fill in the form and submit.
3. Each submission is saved in browser local storage and an updated Excel file is automatically generated:
   - `RT_Knits_Transport_Survey_Responses.xls`

## Notes

- The form includes all required departments and transport service areas.
- Excel export is handled directly in-browser (no backend required and no setup needed).
